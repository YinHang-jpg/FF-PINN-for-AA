# REPRODUCIBILITY.md — Reproduce manuscript figures

All commands assume the repository root as the working directory and that
dependencies from [`ENVIRONMENT.md`](ENVIRONMENT.md) are installed.

```bash
export PYTHONPATH=$(pwd)   # Windows PowerShell: $env:PYTHONPATH = (Get-Location).Path
export MPLBACKEND=Agg
```

Manuscript PNGs are written to `figures/`.

---

## 0. Train the default pack (once)

Default training frequency in the trainers is 8 kHz (standing-wave case used for Fig. 7).
Frequency packs for sweeps live under `PINN/freq_{8,10,12,16}k/`.

```bash
python mechanisms/ARF_PINN_x.py
python mechanisms/ARF_PINN_t.py
python mechanisms/STOKES_PINN_x.py
python mechanisms/STOKES_PINN_t.py
python mechanisms/STOKES_PINN_v.py
```
